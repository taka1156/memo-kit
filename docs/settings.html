固定すると GitHub Actions が memo.config.json を書き換え、全ページを作り直してコミットします。書き込めるのはリポジトリに書き込み権限がある人だけです

  1. 下のボタンで GitHub の Actions のページ（Set accent color）を開く
  2. 右上の「Run workflow」を押し、上の 2 つの値を入力欄に貼る（accent_light が空なら空のまま）
  3. 緑の「Run workflow」を押す。1〜2 分でサイトに反映されます
